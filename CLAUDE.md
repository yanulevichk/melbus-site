# MELBUS — контекст проекта (читать первым)

Отвечай пользователю **на русском**. Пользователь не программист: объясняй простыми словами, пошагово.

## Бизнес
- Курьерская фирма MELBUS (Варшава, ~20 бусов, 5+ лет в логистике, ~30 000 доставок/мес — это обычные посылки, работают субподрядчиком DPD/GLS; DPD/GLS на сайте НЕ упоминать). Запускают новое направление — **полный сервис переездов**: бус + бригада в фирменной форме, белые фирменные коробки, упаковка, погрузка, перевозка, разгрузка, расстановка.
- Бренд сайта = **MELBUS** (как и фирма; фактуры выставляет MELBUS, плательщик VAT). Есть зонтичная идея «MEL» (MELBUS — переезды, MELBUD — стройка), на сайте пока только MELBUS.
- Офиса нет (Google Business Profile — «район обслуживания»). Работают 7/7. География: Варшава + 150 км, межгород по Польше, переезды по ЕС (НЕ Украина/Беларусь). Услуги: всё, кроме хранения (хранение — позже).
- **УТП:** фиксированная цена по видеоосмотру, без доплат на месте; изменения — только с согласия клиента ДО начала работ. Фактура, BLIK/карта.
- Заказов и отзывов пока **нет** → ничего не выдумывать: никаких фейковых отзывов, «довольных клиентов», ИИ-людей под видом настоящих. ИИ-видео помечать «Визуализация».
- Цены: всё brutto; ставки ещё НЕ утверждены (ждут анализа конкурентов) — в UI заглушки «… zł».
- Риски до запуска: OC на машины не покрывает вещи клиентов → нужна OC przewoźnika/OC działalności; реквизиты MELBUS обязательны в футере; фактуры через KSeF; проверить лицензию ЕС для бусов >2,5 т.

## Решения по стилю (утверждено)
- **Логотип:** знак = два квадрата-рамки в изометрии с отверстием по центру (вариант D, «сцеплены»), левые половины бирюзовые, правые серебряные. Надпись MELBUS шрифтом Krona One в кривых: «MEL» белым/графитом, «BUS» бирюзой. Файлы: `public/brand/*.svg`, PNG: `brand/export/`. Генераторы: `brand/build/mark3.py` (знак), `wordmark.py` (локапы), `sheet.py` (лист стиля). Объёмный эскиз из ChatGPT: `brand/source/`.
- **Палитра:** графит #10161D, бирюза #14DCD5 (на тёмном и кнопки с графитовым текстом), глубокая бирюза #077E79 (текст на белом), серебро #DCE1E7, сталь #8F9AA7, бумага #F4F6F8.
- **Шрифты:** заголовки Unbounded, текст Onest (есть кириллица и польские буквы).
- **Сайт:** тёмные первые экраны + светлые разделы, премиальный «кино»-стиль. Должен отлично выглядеть на телефоне (проверять Playwright, iPhone 13).
- Форма бригады: графит + бирюзовый кант, чёрные перчатки с бирюзовыми манжетами, графитовые тканевые бахилы с логотипом. Коробки **белые** с логотипом, бирюзовый скотч, наклейки комнат (цветная полоса + номер + QR).
- Пользователь отклонил: штамп «STAŁA CENA», коричневые коробки. Табло цены — «ок, но не топ», переделать в фирменном стиле.

## Главная: утверждённая концепция (11.11.2026)
- **Первый экран — 3D-диорама «вся квартира в одной коробке»** (three.js, своя графика, без ИИ, логотип точный): сканирование «по видео» → из заготовки складывается белая коробка MELBUS → кровать, диван, холодильник, стол со стульями, шкаф, ТВ, кресло, ковёр, лампа, цветок «ныряют» в неё → клапаны, бирюзовый скотч, наклейка «ПЕРЕЕЗД · КВАРТИРА · 1/1» → бус → проезд через город → в новой квартире всё вылетает по местам. Код: `src/scripts/scenes3d.ts` (`heroScene`), подписи — `Home.astro` (`data-at`).
- Компьютер: сцена закреплена и крутится скроллом (вперёд/назад). Телефон: играет сама по кругу (~22 с), без закрепления.
- Блок «Коробки»: 3D-коробка складывается из заготовки под скролл (`boxScene`).
- **Без полноэкранного прелоадера** (план + SEO). Вместо него логотип в шапке «заклеивается» скотчем при первом заходе. Переход между страницами — графитовая шторка под шапкой.
- Табло цены — барабаны в графитовой панели (`priceBoard` в motion.ts), цифры ДЕМО: `src/data/pricing-demo.ts`.
- Отладка сцен: `/ru/?debug` → `window.__s3d.hero.setProgress(0.5)`, `window.__tl['home-hero'].progress(0.5)`. Постеры и ролики: `tools/scene-poster.cjs`, `tools/scene-film.cjs`.
- Референсы пользователя (видео/ссылки) в проекте НЕ сохранены — в документе-плане только их суть (диорама под скролл, «удар молотком», маскот). Попросить прислать заново и сохранить в `docs/refs/`.
- SEO-чеклист и что сделать к запуску: `docs/SEO.md`.

- Языки: сейчас только **RU** (черновик, `/ru/`), затем PL (основной, без префикса), UA, EN. Таблица адресов: `src/i18n/routes.ts` (enabled-флаги).
- Бренд/контакты: `src/config/brand.ts` (контакты и реквизиты — заглушки TODO).

- Страницы: один маршрутизатор `src/pages/[...path].astro`, шаблоны в `src/views/`. Форма заявки `Quote.astro` — пока макет (CRM — отдельный этап: Cloudflare Workers + D1 + R2, Stripe BLIK/P24, Telegram-бот).
- Прототипы: `prototypes/animation-lab.html`, `prototypes/brand-sheet.html` (артефакт «Фирменный стиль MELBUS»).
- Документ-план (Claude Docs): «Сервис переездов — схема сайта, путь клиента и контент» — карта сайта, путь клиента, политики, CRM, сценарий главной, ИИ-шот-лист.
- Коммиты: в конце сообщения строки Co-Authored-By/Claude-Session, как в истории. Работа идёт в ветке сессии + PR в `main` репозитория yanulevichk/melbus-site.
