MELBUS — сторис «Дневник запуска» для Figma
=============================================

Это импортёр: он один раз сам строит в Figma весь файл со сторис (66 сторис × 4 языка + обложки «Актуального»).
Готовые редактируемые файлы Figma (.fig) снаружи собрать нельзя — поэтому так.

КАК ОТКРЫТЬ (5 минут, нужно приложение Figma для компьютера — в браузере свои плагины не запускаются)
1. Распакуйте этот архив в любую папку.
2. Откройте Figma (приложение) → создайте новый пустой файл дизайна (Design file).
3. Меню (значок Figma слева вверху) → Plugins → Development → Import plugin from manifest…
   → выберите файл manifest.json из этой папки.
4. Меню → Plugins → Development → «MELBUS — сторис (импорт)». Подождите 1–3 минуты (внизу бегут дни 1…28).
5. Готово — сохраните файл (Ctrl/Cmd+S). Импортёр больше не нужен; запускайте его только в новом пустом файле.

ЧТО ВНУТРИ ФАЙЛА
• Страницы: «Сторис PL» (основной), «Сторис RU», «Сторис UK», «Сторис EN», «Актуальное (обложки)», «⚙︎ Компоненты».
• На странице языка — 4 раздела (главы по неделям). В разделе: ряд = день, колонки = 09:00 / 13:00 / 19:00.
• Каждая сторис — фрейм 1080×1920 «D01-1 · 16.11 09:00 · Рубрика». Слои названы по-русски:
  Фото / Затемнение / Шапка (Рубрика, День) / Линия скотча / Текст (Заголовок, Подзаголовок, Пункты…) / Логотип / Визуализация.
• Текст живой (шрифты Unbounded и Onest — есть в Figma). Блок «Текст» — автолейаут: правьте — он перестраивается сам.
  Если текст стал длиннее, поднимите блок, чтобы он не задел логотип (ниже ~1530 px — поле ответа Instagram).
• Цвета — стили «MELBUS/…»: поменяете стиль — поменяется во всех сторис. Логотип — компонент (страница «⚙︎ Компоненты»).
• Скрытые слои «Место для стикера…» — где оставить место для опроса/вопроса в Instagram.

ВЫГРУЗКА
• Выделите фреймы → справа Export → JPG (или PNG), 1x → получится 1080×1920.
• ВИДЕО-сторис (помечены «ВИДЕО»): ролик живёт отдельно (папка marketing/stories/2026-11/hf/ и public/video/).
  Чтобы сделать подпись поверх ролика: скройте слои «Фон…» и «Кадр из ролика…» → Export PNG (прозрачный фон)
  → положите PNG поверх ролика в CapCut или в редакторе Instagram.

ВАЖНО
• Правило языков: если меняете фразу — поменяйте её на всех 4 страницах (PL, RU, UK, EN).
  Или напишите Claude — поменяет в одном месте сразу на 4 языках и пересоберёт и сторис, и этот импортёр.
• ИИ-кадры помечены «Визуализация» — при публикации включите метку Instagram «Создано с помощью ИИ».
