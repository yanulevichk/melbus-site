MELBUS — сторис и посты для Figma (4 языка)
=============================================

Это импортёр: он один раз сам строит в Figma весь файл —
• сторис «Дневник запуска»: 66 × 4 языка;
• посты профиля: обложки 8 Reels, карусели «Переезд за 6 шагов» и «Мы не продаём часы», превью ссылки, обложка Facebook;
• аватар и обложки «Актуального».
Готовые редактируемые файлы Figma (.fig) снаружи собрать нельзя — поэтому так.

КАК ОТКРЫТЬ (5 минут, нужно приложение Figma для компьютера — в браузере свои плагины не запускаются)
1. Распакуйте этот архив в любую папку.
2. Откройте Figma (приложение) → создайте новый пустой файл дизайна (Design file).
3. Меню (значок Figma слева вверху) → Plugins → Development → Import plugin from manifest…
   → выберите файл manifest.json из этой папки.
4. Меню → Plugins → Development → «MELBUS — сторис (импорт)». Подождите 1–3 минуты (внизу бегут дни и разделы).
5. Готово — сохраните файл (Ctrl/Cmd+S). Импортёр больше не нужен; запускайте его только в новом пустом файле.

ЧТО ВНУТРИ ФАЙЛА
• Страницы: «PL · сторис и посты» (основной), «RU …», «UK …», «EN …», «Профиль: аватар и «Актуальное»», «⚙︎ Компоненты».
• На странице языка: сверху 4 раздела сторис (главы по неделям; ряд = день, колонки = 09:00 / 13:00 / 19:00),
  ниже — разделы постов: «Обложки Reels», «Карусель «6 шагов»», «Карусель «Мы не продаём часы»», «Ссылки и Facebook».
• Каждая сторис/слайд — отдельный фрейм нужного размера (сторис 1080×1920, карусель 1080×1350). Слои названы по-русски:
  Фото / Затемнение / Шапка (Рубрика, День) / Линия скотча / Текст (Заголовок, Подзаголовок, Пункты…) / Логотип / Визуализация.
• Текст живой (шрифты Unbounded и Onest — есть в Figma). Блок «Текст» — автолейаут: правьте — он перестраивается сам.
  В сторис: если текст стал длиннее, поднимите блок, чтобы он не задел логотип (ниже ~1530 px — поле ответа Instagram).
• Цвета — стили «MELBUS/…»: поменяете стиль — поменяется везде. Логотип — компонент (страница «⚙︎ Компоненты»).
• Скрытые слои «Место для стикера…» — где оставить место для опроса/вопроса в Instagram.

ВЫГРУЗКА
• Выделите фреймы → справа Export → JPG (или PNG), 1x.
• ВИДЕО-сторис (помечены «ВИДЕО»): ролик живёт отдельно (marketing/stories/2026-11/hf/ и public/video/).
  Подпись поверх ролика: скройте слои «Фон…» и «Кадр из ролика…» → Export PNG (прозрачный) → наложите на ролик в CapCut/Instagram.
• REELS: здесь — обложки (их можно править и выгружать). Надписи внутри самих роликов — в видео; чтобы их поменять,
  напишите Claude — он поменяет текст на 4 языках и пересоберёт ролики.

ВАЖНО
• Правило языков: если меняете фразу — поменяйте её на всех 4 страницах (PL, RU, UK, EN).
  Или напишите Claude — поменяет в одном месте сразу на 4 языках и пересоберёт и картинки, и этот импортёр.
• ИИ-кадры помечены «Визуализация» — при публикации включите метку Instagram «Создано с помощью ИИ».
