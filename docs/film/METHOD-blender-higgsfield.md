# Методичка: кино-ролик с точной камерой — Blender (превиз) → Higgsfield (Seedance) → Remotion (монтаж)

Проверено на проекте MELBUS (ноябрь 2026): 42-секундный фотореалистичный фильм «вся квартира в одной коробке», 5 кусков Seedance, склейка без видимых стыков, итоговый монтаж 23 с с замедлениями. Потрачено ≈ 175 кредитов Higgsfield на видео + 1,5 на кадры стиля.

**Главная мысль.** ИИ-видео не умеет «придумать» сложную камеру и точное движение предметов. Поэтому камеру и движение мы **сначала строим сами в 3D (превиз)**, проверяем, что ничто ни во что не врезается, и только потом отдаём ИИ серое видео как образец движения — он «перекрашивает» его в фотореал, сохраняя камеру и тайминг.

---

## 0. Правила работы с заказчиком (обязательно)
- **Перед каждой платной генерацией** назвать точную цену (через `get_cost: true`) и дождаться «да».
- Сначала дешёвое: превиз (бесплатно) → картинки (≈0,25 кр.) → черновики видео 480p → финал 1080p.
- Логотип в генерации — только образцом; ИИ рисует его ~90% точно. На крупных планах накладывать настоящий при монтаже.
- ИИ-видео помечать «Визуализация». Без ИИ-людей с лицами под видом настоящих (только руки/силуэты).

## 1. Превиз в Blender (бесплатно): камера и движение

### Установка (Linux, без экрана)
```bash
apt-get install -y blender libegl1 libegl-mesa0 libgl1-mesa-dri libgbm1
blender -b -noaudio --factory-startup -P previz.py -- none 960 540 0 1008 --save previz.blend
blender -b previz.blend -noaudio -o out/f#### -F PNG -s 0 -e 1008 -a      # можно 4 процесса по диапазонам кадров
```
Рендер — **Workbench** (быстро, серые модели), `view_transform='Standard'`, студийный свет, cavity. Cycles не нужен.

### Как строить сцену (всё скриптом на Python)
- Простые формы (box/cylinder/ico) **в реальном масштабе** (метры). Комнаты, мебель, бус, улица, дома.
- Для удобства держать координаты «как в three.js» и функцию перевода `P(x,y,z) = (x, -z, y)`.
- Каждый объект анимируется **по ключам на каждый кадр** из функций состояния `state(t)` (позиция, поворот, масштаб) — так легко менять тайминг одной цифрой.
- Тайминг — константы вверху файла: `T_WALLS = (8.3, 9.7)`, `T_DOORS = (21.4, 22.0, 25.0, 25.6)` и т.д.

### Камера — «дроновая», а не статичная
- Список опорных точек `KEYS = [(t, позиция, цель, объектив_мм), …]` + процедурные участки (спираль над объектом, проезд за машиной, пролёт под днищем) — тоже генерируются как точки.
- Между точками — **гладкая интерполяция Эрмита/Catmull-Rom по времени**, цель камеры — через Track-To.
- Объектив меняется по ходу (17–45 мм): широкий для пролётов, длинный для деталей.
- Ошибки, которые заказчик видит сразу: «камера стоит» (мёртвый кадр), «камера теряется» (смотрит в пустоту), «рывок» (резкий поворот за 0,5 с), «упирается в предмет». Правило: **каждый поворот взгляда ≥ 1 с**, цель камеры всегда на главном действии.

### Логика действия (чтобы ИИ понял сюжет)
- Предмет не появляется «из ниоткуда»: заготовка коробки лежит на полу с первого кадра.
- Вещи сначала **поднимаются вертикально**, потом летят дугой, садятся тоже вертикально (не задевают соседей); разворачиваются, пока высоко.
- Погрузка — через задние двери и пандус (понятная механика), двери закрываются перед камерой = **естественная склейка**.
- Порядок «физически правильный»: ковёр распаковывается первым, мебель встаёт на него.

### Проверка столкновений — ОБЯЗАТЕЛЬНО (заказчик видит «микроудары»)
Скрипт проходит каждый кадр и сравнивает габариты (AABB) деталей:
1. камера внутри предмета (запас 6 см);
2. главный объект (коробка) против машины, стен, деревьев;
3. летящие вещи против стен, машины, **друг друга** и стенок коробки.
Плюс справка «камера ближе 15 см к чему-либо» и «вещь ближе 2 м к объективу» (иначе в ИИ-видео это тёмное пятно у камеры).
**Без `TOTAL 0` превиз не показывать и не отдавать в ИИ.**

### Нарезка на куски для ИИ
- Seedance 2.5 берёт 4–30 с, но качество лучше на кусках **≈ 7–11 с**.
- Резать по естественным переходам: кран вверх, двери закрываются перед камерой, машина уезжает.
- Каждый кусок — чистое MP4 (без подписей) 960×540, 24 к/с, ровно той длины, что запросите у ИИ (`duration`).

## 2. Кадры стиля (Higgsfield, GPT Image) — утвердить «вид» до видео
- Модель `gpt_image_2_6`, ≈0,25 кр. за кадр. По 1 кадру на кусок.
- Образцы (`medias` role `image_references`): **кадр превиза** (композиция) + логотип.
- Шаблон подсказки:
  > Reference image 1 is a grey untextured 3D previz frame: keep EXACTLY its camera angle, framing, composition and the position and size of every object, but do not copy its grey look. Re-create it as a photorealistic cinematic film still. Scene: … Golden hour, warm low sun, long soft shadows, subtle haze, shallow depth of field, anamorphic lens look, high-end commercial. No text except the logo, no people.
- Решения стиля спросить у заказчика заранее: реализм (кино/миниатюра), машина (силуэт, без значков производителя), свет (золотой час), откуда-куда (новостройка → дом).

## 3. Видео по превизу (Higgsfield, Seedance 2.5 omni_reference)

### Параметры
```
model: seedance_2_5, mode: omni_reference, draft: true (480p черновик), duration: <длина куска>,
aspect_ratio: 16:9, generate_audio: false
medias:
  - превиз-кусок         role: video_references
  - стартовый кадр       role: start_image        (со 2-го куска — см. «цепочка»)
  - кадры стиля / логотип role: image_references
```
Цены (ноябрь 2026): черновик ≈ 3 кр./с (11 с = 33 кр.), 1080p ≈ 16 кр./с; черновик можно «дорендерить» в 1080p через `draft_job_id` (платится полная длина).

### Шаблон подсказки
> Photorealistic cinematic film at real-world scale, one continuous shot with no cuts. The first frame is the start image. The reference video is a grey untextured 3D previz: follow it EXACTLY for the camera path, camera speed, framing, timing, and the position and motion of every object. Do not copy its grey look — it is only a layout and motion guide. The look comes from the reference images: …
> 0–1 s: … 1–3 s: … (тайминг по секундам куска, что происходит)
> Golden hour …, stabilized gimbal camera … Objects never pass through each other. No text other than the logo, no people, no hands, no faces.

### Цепочка кусков без стыков (ключевой приём)
1. Сгенерировать кусок 1.
2. Взять из него кадр **ровно на границе** следующего куска (например кадр 182 при 24 к/с = 7,6 с), загрузить как `start_image` для куска 2.
3. Повторить для каждого следующего куска. Граничный кадр выбирать там, где действие совпадает с началом следующего превиз-куска (смотреть контактный лист кадров около границы).
4. При склейке брать из каждого куска кадры **до** граничного (ffmpeg `trim=end_frame=N`, `concat`). Стыки получаются незаметными.

### Ошибки, которые мы поймали (и как лечить)
- **Кадр стиля «из будущего»** (коробка уже с мебелью) в куске, где коробка ещё пустая → ИИ сразу кладёт вещи в коробку. Давать только образцы того состояния, которое есть в куске; прямо писать «the box is completely EMPTY until …».
- **Резкий нырок камеры в превизе** → ИИ рисует «белый ком»/плиту у объектива. Лечится в превизе: плавный кран, взгляд скользит.
- **Вещи близко к объективу** → тёмные пятна. Держать ≥ 2 м от камеры в превизе.
- **ИИ иногда сам вставляет склейку** в конце куска → брать кадры только до нужной границы.
- Логотип на крупных планах читается, на мелких — «каша»: на монтаже накладывать настоящий.

## 4. Короткие ролики для блоков сайта (Kling 3.0)
- Сначала 2 варианта картинки (GPT Image, 0,25 кр.) → выбрать → ролик **Kling 3.0 pro, 5 с, без звука** (`sound: off`) ≈ 8,75 кр., картинка = `start_image`.
- Движения простые: машина проезжает (камера ведёт), руки кладут предмет, рука с телефоном панорамирует.
- Для бесшовного повтора на сайте: последние 0,5 с перетекают в начало (ffmpeg `xfade`), либо мягкое затемнение в цвет фона.

## 5. Монтаж и резкость (бесплатно): ffmpeg + Remotion
- **Склейка** кусков: ffmpeg `trim/concat`.
- **Резкость** без ИИ: `hqdn3d=1.2:1.2:2:2, scale=1920:1080:flags=lanczos, cas=0.9, unsharp=5:5:0.5:3:3:0` → кадры JPG 1080p.
- **Замедления**: дорисовать кадры `minterpolate=fps=72:mi_mode=mci:mc_mode=aobmc:me_mode=bidir:vsbmc=1` (24→72 к/с).
- **Ритм (главное для «вау»)**: не ускорять всё подряд. Проходные куски — быстро (2,5–4×), детали — замедлить (0,5–0,75×): предмет ныряет в коробку, скотч, двери с логотипом, пролёт под днищем, финал. Плавный разгон/торможение на стыках (≈0,2 с).
- В Remotion: таблица `SEGMENTS = [[начало, конец, скорость], …]` → посчитать для каждого кадра нового ролика место в исходнике; на обычной скорости брать только настоящие кадры, дорисованные — только в замедлениях. **Не смешивать соседние кадры** (motion blur склейкой) — даёт двоение логотипа.
- Итог: 42 с → 23 с, 1080p. Remotion бесплатен для фирм до 3 сотрудников, иначе нужна Company License — предупредить заказчика.

## 6. На сайте
- Компьютер: секция закреплена, прокрутка ведёт фильм (кадры WebP на canvas, ≈270 кадров по ~32 КБ, грузить «скелетом»: каждый 8-й, потом остальные). **Темп ограничить**: прокрутка задаёт цель, фильм идёт к ней не быстрее ×1,5 (назад быстрее) — иначе рывок колесом проматывает фильм.
- Телефон: тот же фильм видео 540×960 без звука по кругу, подписи по времени видео.
- Подписи на замедлениях, финал с кнопкой; полная версия — кнопкой «Смотреть ролик».

## 7. Чек-лист по шагам
1. Решения стиля с заказчиком (реализм, машина, свет, откуда-куда).
2. Превиз в Blender → видео заказчику → правки до «ок».
3. Проверка столкновений → `TOTAL 0`.
4. Кадры стиля (цена → «да») → утвердить вид.
5. Черновик 1-го куска (цена → «да») → проверить, как ИИ держит камеру.
6. Остальные куски цепочкой через `start_image`.
7. Склейка → резкость → монтаж с ритмом (Remotion) → сайт/соцсети.
