# Как включить приём заявок (Telegram + видео) — по шагам

Код уже готов и проверен. Нужно один раз (≈ 30–40 минут) создать бота, аккаунт Cloudflare и вписать два секрета.
Пока этого нет, форма на сайте покажет клиенту: «Не получилось отправить — напишите в WhatsApp».

## Как это работает
1. Клиент заполняет форму (обязателен только телефон) и прикрепляет видео квартиры прямо с телефона — любого размера, до 2 ГБ на файл.
2. Видео грузится кусками по 10 МБ в хранилище Cloudflare R2 (если связь моргнула — кусок повторяется сам).
3. В вашу Telegram-группу приходит сообщение: номер заявки, имя, телефон с кнопкой «открыть WhatsApp», адреса, этажи, лифт, дата, вещи, услуги, комментарий, ориентир из калькулятора и **ссылки на видео** (открываются прямо в телефоне, с перемоткой; ссылка живёт 60 дней, чужой человек её не откроет).
4. Клиент видит «Принято! Заявка № M-261112-K4F2» и что ответим в течение 2 часов днём.
5. Боты-спамеры отсекаются (скрытое поле-ловушка + проверка времени заполнения).

## Шаг 1. Бот в Telegram (5 минут)
1. В Telegram найдите **@BotFather** → `/newbot` → имя «MELBUS Заявки» → адрес, например `melbus_zayavki_bot`.
2. BotFather пришлёт **токен** (длинная строка вида `123456:ABC...`). Никому его не показывайте и не пишите в чат с Claude.
3. Создайте группу «Заявки MELBUS», добавьте туда себя, коллег и бота.
4. Узнать **id группы**: напишите в группе `/start` (команды бот видит всегда), затем откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе найдите `"chat":{"id":-100…` — это число (с минусом) и есть id.

## Шаг 2. Cloudflare (15–20 минут)
1. Зарегистрируйтесь на cloudflare.com (бесплатно).
2. **Workers & Pages → Create → Pages → Connect to Git** → выберите репозиторий `melbus-site`.
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Ветка: `main` (после того как PR вольют).
3. **R2** (хранилище видео): включить R2 (попросит карту — 10 ГБ бесплатно, дальше копейки) → **Create bucket** → имя `melbus-videos`.
   - В настройках бакета: **Object lifecycle rules → Delete objects after 60 days** (видео клиентов не храним вечно — это и про RODO, и про деньги).
4. В проекте Pages: **Settings → Variables and Secrets** → добавить как *Secret*:
   - `TELEGRAM_BOT_TOKEN` = токен из шага 1;
   - `TELEGRAM_CHAT_ID` = id группы (с минусом).
5. **Settings → Bindings → R2 bucket**: имя переменной `VIDEOS`, бакет `melbus-videos` (если не подхватилось само из `wrangler.toml`).
6. Пересобрать сайт (Deployments → Retry deployment). Отправить тестовую заявку — она придёт в группу.

## Шаг 3. Домен
Купить `melbus.pl` (если ещё нет) и в Cloudflare Pages → **Custom domains** → добавить домен. Cloudflare сам выпустит HTTPS.

## Если что-то не работает
- Заявка не приходит: проверьте токен и id группы, бот должен быть **участником** группы.
- Видео не грузится: проверьте привязку `VIDEOS` к бакету `melbus-videos`. Без хранилища заявка всё равно уйдёт, а в сообщении будет «видео не загрузилось — попросите прислать в WhatsApp».
- Появился спам: включить бесплатную защиту Cloudflare Turnstile (≈ 15 минут работы, скажите Claude).

## Для разработчика
- Функции: `functions/api/quote.ts`, `functions/api/upload/{start,part,complete}.ts`, `functions/api/video/[[key]].ts`; общий код — `server/`.
- Текст сообщения в Telegram — `server/message.ts` (подписи берутся из `src/content/quote.ts`).
- Проверка у себя: `npm run build`, затем
  `npx wrangler pages dev dist --binding TELEGRAM_BOT_TOKEN=… --binding TELEGRAM_CHAT_ID=…`
  (для теста без настоящего Telegram: `--binding TELEGRAM_API=http://127.0.0.1:9999` и любой простой сервер, который пишет запросы в файл).
- Лимит бесплатного тарифа: 100 000 обращений к функциям в день, 10 мс процессора на обращение — куски видео идут в R2 потоком, без буферизации.
